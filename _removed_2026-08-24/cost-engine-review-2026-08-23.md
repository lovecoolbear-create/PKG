# 成本分析引擎全局审查与验证（2026-08-23）

> 范围：成本 5 维引擎、编排层、校验、简化模型口径、油墨归属（本次刚从加工费移到材料维度）。
> 方法：静态通读核心源码 + 实证跑全部可运行脚本 + 构建。

## 一、维度架构

| 维度 | 键 | 口径要点 | 是否随地域浮动 |
|---|---|---|---|
| 材料 | `material` | 面纸/坑纸/裱坑/灰板 + **油墨**（本次移入） | 否 |
| 人工 | `labor` | 固定元/个×复杂度 + 糊盒 + 换线 0.5h×地域费率 | **是唯一浮动项** |
| 加工费 | `process` | 印刷/表面处理/模切/刀模 + 设备·开机费 | 否（地域系数不进加工费） |
| 设计制版 | `design_plate` | 一次性固定费（制版+设计+打样） | 否 |
| 财务 | `finance` | 物流/包装/管理/利润（物流按 subtotal% 简化） | 否 |
| 审阅 | `review` | 只读跨维度一致性，不改数字 | — |

维度构成稳定，无重复计（人工/设备已与加工费去重，地域差异只保留在人工）。

## 二、数据流向

```
input
  → applyDefaults（未填/跳过字段；默认假设独立归集，不污染完整度）
  → calculateCompleteness（基于用户原始填写，默认假设另透明标注）
  → deriveAnalysisContext（dataflow：一次算全部共享派生量：面积/数量/损耗率/地域/色数…）
  → runAllAgents（6 个 deterministic 函数，只读消费 ctx，无互相调用）
  → calculateRatios（补 ratio/amountRange）
  → validate（仅 warning，无 error）
  → reviewAnalysis（只读审阅）
  → 默认假设对各维度置信度降级
  → 组装 AnalysisReport（9 固定模块 + 透明化字段）
```

非零通信形态只有「共享派生上下文」一种，符合既定架构决策（禁止 agent 互调 loop）。

## 五、发现与建议（按优先级）

1. **[已处理] 油墨归属**：已从加工费移到材料维度；`materialAgent` 接入 `cmykColors/spotColors`，`processAgent` 已移除油墨计算；文档 §4.1/§4.3/§5/§10 与 `ink-cost-model.md` 全同步；`getProcessRate("ink:*")` 入口不变。
2. **[提示，非 bug] 阈值不一致**：`validate` 占比越界用 `maxR+5`（设计=15%）才 warning；`buildSmallBatchNote` 用 `expectedMax`（设计=10%）即显示。设计占比 10%–15% 时小批量提示显示但校验无 warning——属合理（提示更敏感、不当错误处理），建议在文档统一说明避免混淆。
3. **[待办] 真实校准数据缺失**：`calibration-real` 示例均为示意值，无法得出真实偏差结论。需用户攒 10–20 例真实报价（写入 `calibration-cases.json`）才能跑第一轮真实校准（阶段 1→2 反推常数）。
4. **[已知缺口] 精度瓶颈在真实数据底座**：材料静态价表 + 设计制版绝对水平 → 大批量/多专色易越界，需路线图三期真实成交价库/纸价 API/多地域费率收敛到可报价级（±10%）。
5. **[清理] 历史脚本**：`scripts/color-print-box-check.ts` 不存在（已移除），验证时剔除；盒型专项校验若需可重建。
