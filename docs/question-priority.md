# 追问（澄清提问）优先级与话术设计

> 目标：让客户/用户**用最少的交互**补齐对成本影响最大的变量，先把估算从"粗"拉到"可用"，再逐步细化。
> 原则：① 先图纸/自然语言自动识别，只追问**不确定或缺失**的高影响项；② 每轮少而精准，不抛长问卷；③ 透明展示完整度并提示"补什么能显著降低误差"。

---

## 一、追问优先级列表

按"对单只成本的影响强度"分两级。层级是提问排序的唯一主导因素，权重用于同级内排序。

### 高影响（必问，缺一项就会显著拉大误差）

| 顺序 | 字段 | 权重 | 为什么是高影响 |
| ---: | --- | ---: | --- |
| 1 | 订单数量 `quantity` | 15 | 决定材料采购单价与开机费分摊，小批量单只成本波动最大 |
| 2 | 长 `length` | 12 | 长×宽×高共同决定展开面积与用纸量（材料成本主驱动） |
| 3 | 宽 `width` | 12 | 同上 |
| 4 | 高 `height` | 12 | 同上 |
| 5 | 材质 `material` | 12 | 纸种是材料成本核心，白卡/铜版/灰底白/牛皮/特种价差可达数倍 |
| 6 | 克重 `grammage` | 11 | 直接决定材料单价与盒体挺度 |
| 7 | 印刷方式 `printMethod` | 10 | 胶印/数码/柔印影响制版费与单位印刷成本，小批量数码更划算 |
| 8 | 交付地点 `deliveryLocation` | 9 | 影响物流/包装成本，**并决定人工地域系数**（华东/华南工价不同） |
| 9 | 表面处理 `surfaceTreatment` | 9 | 覆膜/UV/烫金/凹凸单价各异，烫金还需电化铝与烫金版 |
| 10 | 是否糊盒 `needGluing` | 8 | 增加人工与设备工时 |

> 说明：地域统一问 `deliveryLocation`（而非单独的 `laborRegion`）。引擎中 `laborRegion` 未显式选择时回退到 `deliveryLocation`，一个字段同时驱动"物流成本"与"人工系数"，避免用户被两个地域选择器困惑。

### 次优先级（影响较小或可由默认覆盖，高影响补完后再提示）

| 顺序 | 字段 | 权重 | 影响说明 |
| ---: | --- | ---: | --- |
| 1 | 盒型 `boxType` | 8 | 天地盖用纸率低、工序多，复杂度≈标准盒 1.35 倍 |
| 2 | 专色色数 `spotColorCount` | 5 | 专色需额外调色/洗车与专色版费 |
| 3 | 是否已提供完稿 `provideReadyDesign` | 4 | 已提供可印刷完稿时设计费可减免为 0 |
| 4 | 交期 `targetDelivery` | 4 | 加急可能产生加急费与加班排产成本 |

### 每轮呈现规则（`selectQuestionsForRound`）
- 高影响项未全部补齐前：**只展示高影响项，每轮最多 3 条**（`maxHigh=3`）；用户答一条，该条消失，下一轮自动补入下一条高影响项。
- 高影响项全部补齐/跳过后：再展示次级项，每轮最多 2 条（`maxSecondary=2`）。
- 效果：首屏最多 3 个问题，且都是"最贵变量"，避免一次性长问卷劝退用户。

## 二、推荐话术

每个字段对应一句话问题 + 一句"为什么问"（影响说明），直接用于 `QuestionCard`。

| 字段 | 推荐问题（话术） | 影响说明（impact） |
| --- | --- | --- |
| 订单数量 | 预计订单数量大概是多少个？ | 数量决定材料采购单价与开机费分摊，是单只成本波动最大的变量 |
| 长 | 盒型外尺寸——长是多少 mm？ | 长×宽×高共同决定展开面积与用纸量，直接驱动材料成本 |
| 宽 | 盒型外尺寸——宽是多少 mm？ | 同上 |
| 高 | 盒型外尺寸——高是多少 mm？ | 同上 |
| 材质 | 主体用的是什么纸？（白卡/铜版/灰底白/牛皮/特种） | 纸种是材料成本的核心决定因素，价格差异可达数倍 |
| 克重 | 纸张克重是多少？（如 250/300/350/400g） | 克重直接决定材料单价与盒体挺度 |
| 印刷方式 | 采用哪种印刷方式？胶印 / 数码 / 柔印？ | 影响制版费与单位印刷成本；小批量数码更划算、大批量胶印更省 |
| 交付地点 | 货送到哪个区域？（华东/华南/华北/…） | 影响物流与包装成本，并决定人工地域系数（华东/华南工价不同） |
| 表面处理 | 表面做什么处理？覆膜 / UV / 烫金 / 凹凸？ | 每种工艺单价不同；烫金还需电化铝与烫金版费 |
| 是否糊盒 | 需要糊盒成型吗？ | 糊盒增加人工与设备工时 |
| 盒型 | 是什么盒型？扣底 / 天地盖 / 开窗？ | 天地盖用纸率低、工序多，结构复杂度≈标准盒 1.35 倍 |
| 专色色数 | 有专色吗？几个专色？ | 专色需额外调色/洗车与专色版费，对成本影响明显 |
| 是否已提供完稿 | 是否已提供可印刷完稿文件？ | 已提供可印刷完稿时，设计费可减免为 0 |
| 交期 | 交期要求？标准 / 加急 / 特急？ | 加急可能产生加急费与加班排产成本 |

> 话术统一语气：中立、具体、点明影响，不夸大。已识别字段不打扰（图纸/自然语言解析填充后不再追问）。

## 三、完整度计算逻辑建议

### 现状（`completeness.ts`）
- 遍历 `config.fields`，`score = 已填权重和 / 总权重和 × 100`。
- `missing` 列表 = 未填且 `required || weight>=8` 的字段，按权重降序。
- 置信度惩罚阈值：≥90→0、≥75→5、≥60→12、≥40→20、否则 30。
- 已知偏差：`deliveryLocation` 原权重仅 6，未体现"高影响"，已调为 **9** 使其进入高影响口径。

### 建议（提升"完整度→误差"的可解释性）
1. **权重与追问优先级同源**：追问优先级已是影响强度的权威排序，建议 `config.fields[].weight` 与之对齐（当前已基本一致，仅 `deliveryLocation` 已修正）。避免"追问问 A、完整度却不算 A"的割裂。
2. **分两级口径展示**：完整度可拆成"高影响完整度"与"总完整度"两个数字——高影响完整度达 100% 即可判为"可出初步报价"，次级项是否补齐只影响精细度。推荐在提示文案用高影响缺失项驱动。
3. **提示文案规则（`getCompletenessPrompt`）**：
   - 完整度 ≥ 90% → 绿色，文案："信息已较完整，估算误差较小，可直接用于初步测算与商务沟通。"
   - 60% ≤ 完整度 < 90% → 琥珀，文案："当前信息完整度 X%。补充以下信息可将估算误差明显降低：{高影响缺失前 3 项}。"
   - 完整度 < 60% → 红色，文案："当前信息完整度 X%。补充以下信息可将估算误差显著降低：{高影响缺失前 3 项}。"
   - 核心固定短语"补充以下信息可将估算误差显著降低"已按需求落文案。
4. **降级兜底**：若高影响项全部缺失，提示列出全部高影响字段；若仅次级缺失，提示聚焦次级，避免啰嗦。

### 维度置信度联动（`getDefaultPenaltyForDimension`）
- 某维度用了默认假设才扣分（最高 25/维度）。本次把 `labor` 维度的关联字段由 `laborRegion` 改为 `deliveryLocation`，并加入 `provideReadyDesign` 到 `design_plate`，使"地域/完稿用默认"能正确下调对应维度置信度。
