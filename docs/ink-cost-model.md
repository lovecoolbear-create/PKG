# 油墨成本简化模型

> 状态：已落地（简化版）。本模型独立于「机器+印版」印刷费，单独量化油墨消耗。
> 定位：透明展示 + 可校准，非精确实测；后期用真实成交数据迭代。

## 1. 为什么单独建模

原印刷费 `(数量/1000) × 印刷单价(元/色/千印) × 色数` 把机器、印版、油墨**打包**在「元/色/千印」里，油墨从未被显式量化。
真实报价中油墨是独立消耗品（随印量、色数、覆盖面积线性增长），单独建模后：

- 印刷费结构更透明（客户能看到「机器+印版」与「油墨」各占多少）；
- 专色的高成本终于有对应出处（专色墨量更高、定制墨单价更高）；
- 为后续 VAVE（换墨/减色/局部上墨）提供可优化的量化抓手。

## 2. 公式

```
油墨成本 = 印刷面积(m²) × 墨量系数(g/m²) × 油墨单价(元/kg) / 1000

印刷面积   = netAreaM2(单只展开面积) × 数量        // 默认单面；双面需 × 面数
四色油墨   = 印刷面积 × INK_CMYK_GRAMMAGE_PER_M2 × INK_CMYK_PRICE_PER_KG / 1000
专色油墨   = 印刷面积 × 专色数 × INK_SPOT_GRAMMAGE_PER_M2 × INK_SPOT_PRICE_PER_KG / 1000
油墨合计   = 四色油墨 + 专色油墨
```

- 四色(CMYK)：4 色综合平均覆盖率，墨量系数取 **5 g/m²**；普通四色墨单价 **42 元/kg**。
- 专色：实地覆盖、墨量更高 → 墨量系数 **8 g/m²/专色**；定制/小批量调墨单价更高 → **90 元/kg**。

## 3. 默认系数与单价（可经知识库覆盖）

| 常量 | 默认值 | 含义 | 知识库键（覆盖用） |
| --- | --- | --- | --- |
| `INK_CMYK_GRAMMAGE_PER_M2` | 5 | 四色综合墨量 g/m² | `process_rate::ink:cmyk_grammage_per_m2` |
| `INK_CMYK_PRICE_PER_KG` | 42 | 四色油墨 元/kg | `process_rate::ink:cmyk_price_per_kg` |
| `INK_SPOT_GRAMMAGE_PER_M2` | 8 | 单专色墨量 g/m²（实地） | `process_rate::ink:spot_grammage_per_m2` |
| `INK_SPOT_PRICE_PER_KG` | 90 | 专色油墨 元/kg | `process_rate::ink:spot_price_per_kg` |

覆盖方式：在知识库 `process_rate` 分类下写入上述 key 的数值条目，引擎经 `getProcessRate()` 自动读取，
回退到代码常量。报告拆解行会标注「（知识库覆盖）」或「（默认系数）」。

## 4. 已知简化与偏差方向

- **默认单面印刷**：双面印件未 × 面数，偏低估约一半油墨（占整体成本极小，影响可忽略）。
- **专色按整面实地覆盖**：实际专色多为局部（logo/色块），本模型偏**保守（高估）**。若典型专色覆盖率约 30%，
  可将 `INK_SPOT_GRAMMAGE_PER_M2` 视为「等效全覆墨量」，或后续引入专色覆盖率参数。
- **未区分印刷方式墨耗**：胶印/柔印/数码的墨转移效率不同，本模型用同一系数。
- **未建模洗车/调墨损耗**：专色调墨、洗车损耗已用 `spot_color_setup` 固定费近似，未计入油墨重量。

## 5. 校准路径（后期接真实数据）

1. 收集真实报价单的「油墨/印刷耗材」分项（阶段 0 案例模板已含 `process` 维度，可细分）。
2. 反推实际墨量系数：实测油墨重量 ÷ 印刷面积 ÷ 数量 → 修正 `INK_*_GRAMMAGE_PER_M2`。
3. 反推实际墨价：细分四色 vs 专色采购单价 → 修正 `INK_*_PRICE_PER_KG`。
4. 引入专色覆盖率、印刷面数、印刷方式墨耗差异作为可选参数（不改主公式结构）。
5. 系数写入知识库 `ink:*` 条目，无需改代码即可生效。
